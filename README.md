# Nature Landing Page

## About the Project
A simple and attractive landing page developed using HTML and CSS.

## Technologies Used
- HTML5
- CSS3
- Google Fonts
- Font Awesome
- Google Maps

## Features
- Navigation Bar
- Home Section
- About Us Section
- Services Cards
- Contact Form
- Social Media Icons
- Google Maps Integration

## How to Run
1. Download the project.
2. Open the project folder.
3. Open index.html in your browser.
